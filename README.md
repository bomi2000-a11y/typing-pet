# 타닥펫

제작 BONASSAM · © 2026 BONASSAM. All rights reserved.

한컴타자에서 연습한 기록을 입력하면 펫이 자라는 웹 앱입니다.
사용자는 8~11세 초등학생이에요. 앱 안의 글은 짧고 간결하게, 타수와 정확도는 숫자 그대로 보여 줘요.
처음에는 어떤 동물이 나올지 모르는 알(또는 선물 상자)을 받습니다. 닭·공룡·용은 알에서, 강아지·곰은 선물 상자에서 나와요.
정체가 드러나면 이름을 지어 주고, 4단계로 키워 어른이 되면 명예의 전당에 올린 뒤 새 친구를 맞이합니다.
PC에서는 연습·기록 입력·기록 보기, 휴대폰에서는 펫 상태와 기록 보기만 할 수 있습니다.

## 0. 준비물

- Node.js LTS 버전 (https://nodejs.org 에서 설치)
- 코드 편집기 (VS Code 추천)
- 나중에 필요: Supabase, GitHub, Vercel 계정 (모두 무료로 시작 가능)

## 1. 개발용 체험 모드로 실행하기 (계정 없이 바로)

압축을 푼 폴더에서 터미널을 열고:

```bash
npm install
npm run dev
```

브라우저에서 http://localhost:5173 을 열면 됩니다.
`.env` 파일이 없으면 개발용 체험 모드가 되고, 기록은 이 브라우저에만 저장됩니다.
오른쪽 아래 🛠 테스트 도구로 하루 지나기, 성장 단계 바꾸기 등을 시험할 수 있어요.

체험 모드와 테스트 도구는 **개발할 때(npm run dev)만** 나옵니다.
실제로 배포한 앱(npm run build)에는 체험 모드가 없고, Supabase 설정이 없으면 "서버 설정이 필요해요" 화면만 보여요.

## 2. Supabase 연결하기 (닉네임 + 비밀번호로 PC와 휴대폰 기록 공유)

1. https://supabase.com 에서 새 프로젝트를 만듭니다.
2. 왼쪽 메뉴 **SQL Editor** 에 `supabase/schema.sql` 내용을 전부 붙여넣고 **Run** 합니다.
   기록(records), 펫(pets), 명예의 전당(hall_of_fame) 테이블과 "본인 데이터만 보기" 보안 규칙이 만들어집니다.
3. **Authentication > Sign In / Providers > Email** 에서
   - Email 사용: 켜기
   - **Confirm email: 끄기** (닉네임 로그인은 실제 메일을 쓰지 않으므로 꼭 꺼야 바로 시작할 수 있어요)
4. **Project Settings > API Keys** 에서 Project URL과 공개 키(publishable 또는 anon 키)를 복사합니다.
   service_role / secret 키는 절대 쓰지 마세요.
5. `.env.example` 을 복사해 이름을 `.env` 로 바꾸고 값을 채웁니다.
6. `npm run dev` 를 다시 실행하면 시작 화면이 나옵니다.
   - PC에서 **처음 시작**: 닉네임(한글·영문·숫자 2~10자)과 비밀번호(6자 이상)를 정합니다.
   - 휴대폰에서 **불러오기**: 같은 닉네임과 비밀번호를 넣으면 PC에서 입력한 펫과 기록이 나옵니다.

참고
- 닉네임은 내부적으로 `n...@player.tadakpet.app` 같은 주소로 바뀌어 Supabase에 저장됩니다. 메일은 보내지 않아요.
  Supabase가 이 주소 형식을 거절하면 `src/config.js` 의 `ACCOUNT_EMAIL_DOMAIN` 을 바꿔 보세요.
- 비밀번호는 Supabase가 암호화해서 보관합니다. 잊어버리면 메일로 찾을 수 없으니,
  관리자가 Supabase > Authentication > Users 에서 해당 사용자의 비밀번호를 바꿔 주어야 합니다.
- 이미 예전 `schema.sql` 로 테이블을 만들었다면 파일 맨 아래 안내대로 바뀐 부분만 추가하세요. (특히 records 의 hidden, practice_ms 열이 없으면 기록 저장이 실패해요)

## 3. 인터넷에 배포하기 (Vercel)

1. 이 폴더를 GitHub 저장소에 올립니다. (`.env` 는 `.gitignore` 에 있어 올라가지 않습니다)
2. https://vercel.com 에서 **Add New > Project** 로 저장소를 가져옵니다. 프레임워크는 Vite로 자동 인식됩니다.
3. **Environment Variables** 에 `VITE_SUPABASE_URL`, `VITE_SUPABASE_KEY` 를 `.env` 와 같은 값으로 넣고 Deploy 합니다.

## 4. 휴대폰에서 쓰기

1. 휴대폰 브라우저로 배포 주소를 열고 **불러오기**에서 PC와 같은 닉네임·비밀번호를 넣습니다.
2. 홈 화면에 추가하면 앱처럼 실행됩니다.
   - 아이폰(Safari): 공유 버튼 > 홈 화면에 추가
   - 안드로이드(Chrome): 메뉴(⋮) > 홈 화면에 추가
3. 휴대폰에서는 자동으로 읽기 전용 화면이 나옵니다. 앱을 다시 열 때마다 최신 기록을 불러옵니다.

## 규칙 시뮬레이터

```bash
npm run simulate
```
연습 습관 20가지(매일 1~3번, 이틀·사흘에 한 번, 주말만, 쉬었다 다시, 정확도 낮음, 아주 잘 침 등)를 90일씩 돌려
어른까지 걸리는 날, 배부름 상태 비율, 졸업 시점을 보여 주고 규칙 위반을 찾아요. `config.js` 숫자를 바꾼 뒤 비교해 보세요.

## 바꿔 보기 좋은 곳

- 동물별 단계 이름과 이모지: `src/lib/pet.js` 의 `SPECIES` (그림으로 바꾸려면 `StageIcon.jsx` 의 `ART` 에 추가)
- 특별 장면(꿀, 책 읽기, 원반, 하늘 등): `src/lib/moods.js` 의 `SCENES`
- 단계별 필요한 경험치: `src/lib/pet.js` 의 `STAGES`
- 배부름 단계 기준: `src/lib/pet.js` 의 `MOODS`
- 단계별 동작·표정·말: `src/lib/moods.js` 의 `LOOKS` (동작 모양은 `styles.css` 의 `.motion-이름`)
- 배부름: `src/lib/pet.js` 의 `EMPTY_AFTER_HOURS` (지금 72시간 = 3일 동안 100 → 0). 연습하면 언제나 100으로 가득 차요.
- 보상 규칙과 졸업 기준: `src/config.js` 의 `PRACTICE_LEVELS` 와 그 아래 숫자들

## 결과 팝업

기록을 저장하면 팝업이 떠요.
- 펫 상태: 경험치 변화, 배부름, 다음 성장까지 남은 경험치와 "이런 기록이면 약 몇 번"
- 이번 보상: 추천·최고 기록·첫 도전 같은 보상 내역
- 다음엔 이렇게!: 추천 연습을 몇 타·정확도 몇 % 이상 치면 졸업하는지, 오늘 남은 보상으로 무엇에 도전하면 좋은지
- "바로 다음 연습하러 가기"를 누르면 연습 시간이 재지고 한컴타자가 새 탭으로 열려요.

## 배부름

- 기록을 저장해 보상을 받으면 배부름이 100으로 가득 차고, 3일에 걸쳐 0까지 줄어요. 먹은 직후에 더 빨리 줄어서 아침·점심·저녁 사이에도 배고파지는 게 보여요.
- 마지막 연습 뒤 3시간 안: 배부름 / 3시간~1일: 출출 / 1~2일: 보통 / 2~3일: 배고픔 / 3일 넘게: 굶주림
- 매일 한 번 이상 연습하면 늘 보통 이상이에요. 배고팠을수록 먹이를 줄 때 더 반가워해요(냠냠! → 맛있다! → 와, 밥이다! → 살았다, 고마워요!).

## 기록 지우기·고치기 규칙

- 지운 기록은 목록·그래프·요약에서 빠지지만, 보상 횟수와 최고 기록 계산에는 남아요. (지웠다 다시 넣어 보상을 또 받지 못하게)
- 저장 후 10분 안에는 종류·타수·정확도를 고칠 수 있고, 경험치도 다시 계산돼요. 그 뒤에는 메모만 고칠 수 있어요.
- "기록 직접 입력"은 연습 시간을 알 수 없어서 보상이 절반이에요. "한컴타자에서 연습하기"로 시작하면 제대로 받아요.
  (연습하러 간 지 3시간이 지나면 연습 시간이 무효가 돼요)
- 정확도 85% 미만 기록은 하루 2번까지 기본 보상 5XP를 받고, 하루 보상 3번에는 세지 않아요.

## 점수 체계

쉬운 연습만 반복하지 않고 점점 실력이 늘도록 짜여 있습니다.

- 연습 단계: 자리 연습 → 낱말 연습 → 짧은 글 연습 → 긴 글 연습 → 필사. 어려울수록 보상 배율이 큽니다.
- 졸업: 연속 5회 평균 타수와 정확도가 기준을 넘으면 그 연습을 졸업하고(한 번 졸업하면 유지), 졸업하지 않은 가장 쉬운 연습을 추천합니다.
  졸업한 쉬운 연습은 보상이 30%로 줄어듭니다. 더 어려운 연습을 졸업하면 그 아래 연습도 함께 졸업 처리됩니다.
- 추천 연습을 하면 보상 +20%, 같은 날 같은 연습을 또 하면 두 번째는 60%, 세 번째는 40%.
- 보너스: 처음 해 보는 연습 +40, 최고 기록 +30, 최근 평균보다 빨라지면 늘어난 타수의 절반(최대 +30),
  정확도 98% 이상 +10, 졸업하는 순간 +50. (졸업한 연습에서는 보너스 없음)
- 매일 연습 보너스: 오늘 첫 연습 +20XP, 이틀째부터 연속 하루 +5XP (최대 +25XP), 7일마다 +30XP. 같은 날 3시간 쉬었다 오면 +10XP. 정확도 85% 이상 연습에만.
- 성장 기준: 아기 100XP, 청소년 800XP, 어른 2500XP. 초보가 매일 1번이면 약 4주, 매일 2번이면 약 2~3주에 어른이 돼요.
- 기존 규칙 유지: 하루 보상 3회, 정확도 85% 미만은 5XP, 1분 미만 연습은 절반.
- 기록 입력 창에서 저장하기 전에 예상 보상과 그 이유를 미리 볼 수 있습니다.

## 알려진 한계 (다음 단계 아이디어)

- 보상 계산이 브라우저에서 이루어집니다. 개인용이면 충분하지만, 여러 사람이 쓰며 순위를 겨룬다면
  보상 계산을 Supabase 데이터베이스 함수(또는 Edge Function)로 옮겨야 조작을 막을 수 있습니다.
- 기록은 1000개씩 나눠서 모두 불러옵니다. 수만 개가 되면 최근 기록만 불러오도록 바꾸는 게 좋아요.
- 아이폰 홈 화면 아이콘을 예쁘게 하려면 180×180 PNG 아이콘(apple-touch-icon)을 추가하세요.
- 저녁 알림(“오늘 아직 연습 안 했어요”)은 웹 푸시 알림으로 추가할 수 있습니다.
